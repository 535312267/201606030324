# 鸿蒙自定义交互式刻度尺组件

这是一个为鸿蒙(HarmonyOS)环境开发的自定义交互式刻度尺组件，支持滑动选择数值并自动对齐到刻度。

## 功能特性

- ✅ **自定义尺寸**: 宽345px，高135px
- ✅ **自定义背景**: 背景色#F7F7F7
- ✅ **灵活刻度范围**: 支持传入最小值、最大值和步长
- ✅ **差异化刻度**: 每第5个刻度高度18px，其余12px，宽度统一4px
- ✅ **半透明刻度**: 刻度颜色#999999，透明度59%
- ✅ **数值显示**: 每第5个刻度显示对应数字
- ✅ **中心指示器**: 粉色指示器指向当前选中值
- ✅ **滑动交互**: 支持水平滑动选择数值
- ✅ **自动对齐**: 滑动结束自动对齐到最近刻度
- ✅ **实时反馈**: 滑动过程中实时更新数值显示
- ✅ **性能优化**: 使用ForEach动态渲染可见刻度

## 文件说明

### CustomRuler.ets
基础版本，使用Canvas绘制刻度，适合简单场景。

### ImprovedCustomRuler.ets (推荐)
改进版本，使用ForEach动态渲染，性能更好，功能更完善。

## 使用方法

```typescript
@Entry
@Component
struct MyPage {
  @State selectedValue: number = 3000
  
  build() {
    Column() {
      // 使用改进版组件
      ImprovedCustomRuler({
        minValue: 2000,        // 最小值
        maxValue: 4000,        // 最大值
        step: 10,              // 步长
        currentValue: 3000,    // 初始值
        selectedValue: $selectedValue,  // 双向绑定的选中值
        unit: 'ml'             // 单位
      })
      
      Text(`当前值: ${this.selectedValue}ml`)
    }
  }
}
```

## 组件参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| minValue | number | 0 | 刻度尺最小值 |
| maxValue | number | 100 | 刻度尺最大值 |
| step | number | 1 | 刻度步长 |
| currentValue | number | 50 | 初始显示值 |
| selectedValue | number | - | 当前选中值（双向绑定） |
| unit | string | '' | 数值单位 |

## 设计规范

- **尺寸**: 345×135px
- **背景色**: #F7F7F7
- **主刻度**: 高18px，每5个刻度显示一次，显示数值
- **次刻度**: 高12px
- **刻度宽度**: 4px
- **刻度颜色**: #999999，透明度59%
- **指示器颜色**: #FF69B4（粉色）
- **刻度间距**: 8px

## 交互行为

1. **滑动选择**: 用户可以水平滑动选择数值
2. **实时反馈**: 滑动过程中实时更新显示的数值
3. **自动对齐**: 滑动结束后自动对齐到最近的刻度
4. **平滑动画**: 对齐过程使用200ms的缓动动画
5. **边界限制**: 滑动范围限制在设定的最小值和最大值之间

## 性能优化

- 使用ForEach动态渲染只显示可见区域的刻度
- 避免不必要的重绘和计算
- 优化滑动时的响应性能

## 注意事项

1. 确保传入的`minValue`、`maxValue`和`step`参数合理
2. `selectedValue`需要使用`@Link`装饰器进行双向绑定
3. 组件会自动处理边界情况和数值对齐
4. 建议在实际项目中使用`ImprovedCustomRuler`版本以获得更好的性能
